# Service Provider

مشروع نهاية تدريب ال Flutter  في شركة تمكين 
 Flutter Bootcamp – Graduation Project

يستخدم هذا التطبيق State Management عبر GetX، وهو مربوط بـ Backend حقيقي مبني بلغة PHP على إطار العمل Laravel.

بعد إنجاز هذا المشروع، حصلت على شهادة توصية من شركة تمكين لتطوير التطبيقات باستخدامFlutter: https://tamkeen-dev.com/website/trainees/hanen-mushref 

كما أن هذا المشروع أكسبني خبرة كبيرة، فأصبحت أعرف كل الأساسيات بـ Flutter، وتابعت تطوير نفسي وتعلّمت واستمررت بعده، فاصبحت اكثر احترافية ولم تعد خبرتي محصورة بـ Flutter فقط.
